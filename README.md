## Консольная программа для имитации торговли валютами
Программа для имитации торговли валютами, позволяет регистрировать пользователей,
создавать портфели, со списком кошельков валют, симулировать покупку и продажу
валют по кошелькам, обновлять курсы через внешние API.

## Запуск программы
Установка зависимостей:

 - для linux (bash)

curl -LsSf https://astral.sh/uv/install.sh | sh

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

## API-клиенты
Для работы программы требуется обновление данных из сети интернет
Предварительно необходимо зарегистрироваться на сайте
### Инструкция 
Перейдите на сайт https://www.exchangerate-api.com/.
Зарегистрируйтесь — это бесплатно.
После регистрации вы получите персональный API-ключ. Сохраните его
#### Варианты загрузки ключа в программу 
 - Через переменные окружения:

Перед запуском программы введите в консоль

##### для linux (bash)

export EXCHANGERATE_API_KEY="ключ"

##### для windows (powershell)

$env:EXCHANGERATE_API_KEY="ключ"
 - Через файл .env:

Создайте в корневой папке проекта файл .env
в нем записываете:

EXCHANGERATE_API_KEY=ключ

Учтите что обновления exchangerate-api.com в бесплатной версии сильно ограничены

При работе программы может понадобиться запросить обновления только из одного источника

#### Имена API-клиентов:
- CoinGecko
- ExchangeRateApi

## Конфигурация
Конфигурация проекта указана в файле config.json

в ней включены следующие данные:

 - Путь к файлу хранения данных (data_path)
 - Срок актуальности курсов (rates_ttl_seconds)
 - Базовая валюта (base_currency)
 - Путь к файлу логов (log_path)
 - Имя файла логов (log_file_name)
 - Имя логгера (logger_name)
 - Список поддерживаемых валюты (supported_currency)
 - допустимые символы для ввода (allowed_chars)
 - Сигнатура команд с ограничениями (commands_signature)
 - форматы представления даты (data_format_local, data_format_utc)
 - Расширенная информация по валютам (currencies)

## Логгирование данных
Логирование данных производится в файл указанный в config.json

Производится логирование следующих операций:
- Регистрация
- Аутентификация пользователя
- Покупка валют
- Продажа валют
- обновления курсов валют (При обновлении через команду update-rates также выводится в консоль)

# Команды
Консольные команды являются регистрозависимыми, в каждое поле вводится только одно значение.

Ограничения на допустимые символы и сигнатура команд указана в файле config.json
## register 
Регистрация нового пользователя 

Поля для заполнения:

#### --username (str) - не пустой | Имя пользователя
#### --password (str) - не пустой, как минимум 4 символа | Пароль

Ошибки:
Такой пользователь уже существует

## login 
Аутентификация пользователя 

Поля для заполнения:

#### --username (str) - не пустой | Имя пользователя  
#### --password (str) - не пустой, как минимум 4 символа | Пароль

Ошибки: Неправильный пароль

Особенности:
При заходе на другой аккаунта после аутентификации уточнит о допустимости перехода.

## change-password
Смена пароля актуального пользователя

#### --password (str) - не пустой, как минимум 4 символа | Пароль

## get-rate
Получения актуального курса валютной пары, автоматическое обновление при устаревании данных

Поля для заполнения:

#### --from (str) - не пустой, соответствие списку валют | Код исходной валюты 
#### --to (str) - не пустой, соответствие списку валют | Код целевой валюты

Ошибки: 
Отсутствие указанного кода валюты в списке допустимых

## show-rate
Получения актуальных курсов валют с возможностью фильтрации

#### --currency <str> - опционально, соответствие списку валют | фильтр по конкретной валюте
#### --base <str> - опционально, соответствие списку валют | база в которой показывается вывод
#### --top <int> - опционально | Получение топ(n) крипто-валют

Ошибки: 
Отсутствие указанного кода валюты в списке допустимых

## show-portfolio
Показывает портфель всех валютных кошельков пользователя, требует аутентификации(login) перед запуском 

#### --base <str> - опционально, соответствие списку валют | база в которой показывается вывод

Ошибки:
Пользователь не произвел вход, в портфеле отсутствуют кошельки

## update-rates
Обновляет курсы валют в интернете (подробности в разделе API-клиенты).

Обновляет из всех источников если не выбран конкретный через поле --source.

#### --source <str> - опционально | Источник обновления данных из интернета

Ошибки:
Проблемы с доступом к сайтам, отсутствия API-ключа, некорректные входящие данные

## scheduler-run
Обновляет курсы валют в фоновом режиме, частота обновления задана в файле config.json

Ошибки:
Проблемы с доступом к сайтам, отсутствия API-ключа, некорректные входящие данные

## buy
Покупка валюты на кошелек в портфеле, при отсутствии кошелька создается новый

#### --currency <str> - не пустой, соответствие списку валют | код валюты которую покупают
#### --amount <float> - не пустой, положительный | сумма покупаемой валюты

Ошибки:
Пользователь не произвел вход, код валюты не соответствует допустимым

## sell
Продажа валюты с кошелька в портфеле

#### --currency <str> - не пустой, соответствие списку валют | код валюты которую продают
#### --amount <float> - не пустой, положительный | сумма продаваемой валюты

Ошибки:
Пользователь не произвел вход, код валюты не соответствует допустимым
